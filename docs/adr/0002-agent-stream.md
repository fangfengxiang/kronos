# ADR 0002 Agent 运行与流式契约

**状态。** 采纳独立定义 Agent 流以及用确定性替身验证。gRPC 与 SSE 的事件和终止状态见 [Assistant v1 协议设计](../design/assistant-protocol.md)。

## 背景

Agent 请求会持续产生模型输出、工具状态与运行结果。客户端当前收到的事件和外部工具实际产生的副作用可能处在不同阶段。浏览器也有自己的事件交付与断连规则。

## 决策

- 在 Protobuf 中显式定义 Agent 流式 RPC。协议表达事件类别、先后关系和终止语义。请求取消应传到当前运行和可取消的模型、工具操作。
- 将 Blades 接在 Agent 执行边界。首条纵切使用确定性模型替身复现成功、失败、延迟和取消。引入工具时增加可控的工具替身。服务契约由 Kronos 管理。
- 将已发送事件、客户端观察和工具提交分别记录。没有续传契约时，断流报告中断。涉及已提交或未知结果的工具操作，读取权威状态后再决定是否恢复或交接。

## 取舍

gRPC 服务端流与 SSE 交付同一个执行结果。SSE 有独立监听和显式 HTTP 映射，事件格式、完成、失败和取消见 [SSE 与旧协议监听设计](../design/additional-listeners.md)。续传属于独立协议演进。

## 验收

使用固定输入验证事件顺序、成功终态和可观察错误。分别在首条事件前和已有输出后模拟中断，检查取消传播与资源回收。引入有副作用的工具之前，补测工具提交但尚未输出时的断流，核对实际提交次数。
